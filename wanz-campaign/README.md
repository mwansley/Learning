# Wanz — More to the Story

**JLD Imagery · Custom presentation for Wanz · Not for sharing.**

Prepared exclusively for Wanz’s review. Please do not forward, copy, distribute, or reuse without written permission from JLD Imagery.

Campaign ideas, sample videos, and scripts prepared by Jessa / JLD Imagery.

Start with **Wanz Approved**: a thrift-review series that turns the familiar “Thrift Shop” vocal into a reason to watch, respond, and discover more of your music.

## Open the presentation

1. On the repository page, select the green **Code** button, then **Download ZIP**.
2. Unzip the download. Open the **Learning-main** folder, then **wanz-campaign**.
3. Double-click **index.html** to open the presentation in your browser. Keep the **media** folder beside it.

No installation or sign-in is needed to view the downloaded presentation. GitHub shows the HTML file as code; download the folder to see the designed slides.

Use the **left and right arrow keys** or the **bottom arrows** to move through the slides. Select **Present** for a larger view. Select any **format and script** button for the full idea; **Close** returns to the slide.

## The ideas

| Idea | What it is |
| --- | --- |
| Wanz Approved | Thrift finds, store visits, and viewer submissions with your verdict. |
| The Living Room Sessions | A regular live show for requests, stories, songwriting, and local dates. |
| Booking Machine | A booking package for solo, duo, and band performances. |
| Not Done Yet, the Talk | A talk with songs about experience, persistence, and what comes next. |
| Seattle Soul Circuit | Shared Seattle shows built around musicians and their communities. |
| Elder-to-Next-Gen | A filmed musical exchange with a younger artist and a DJ. |
| Seattle Music Stories | Conversations with the people behind Seattle’s music. |
| Remix Trend Riding | Current sounds combined with your own musical ideas. |
| Recording and editing workflow | Turn one recording into several clips, ready for your review. |
| Converge Media feature | A possible interview about the music you are making now. |

The first five are starting options. The next three are ideas to revisit as the campaign develops. The editing workflow supports whichever direction you choose; Converge remains an open possibility.

These are concepts for discussion, with draft scripts to shape in your own voice. A useful first conversation is simply: **Which idea would you enjoy making?**
