## AI relationship onboarding

A facilitated, nine-question conversation that helps clients create a starting guide for how AI should communicate, explain, ask questions, and respect their boundaries.

**DO NOT SHARE — For the intended recipient’s onboarding use.** The materials retain this distribution notice. This repository is publicly accessible.

**[Download the complete onboarding kit](Downloads/Relationship-Onboarding-Kit.zip?raw=true)**

After downloading and extracting the ZIP, open **00-START-HERE.pdf**, then **Relationship-Notebook.html** in a web browser. The notebook works offline; the facilitated AI conversation happens in the AI chat the client chooses.

The kit keeps only the HTML notebook and Start Here PDF at the top level. Optional materials are grouped into Print, Facilitator, and Reference folders.

- [Browse the kit](AI-Relationship-Onboarding/)
- [Start Here card](AI-Relationship-Onboarding/00-START-HERE.pdf)
- [Printable client notebook](AI-Relationship-Onboarding/Print/Client-Preview-Notebook.pdf)

The HTML includes optional preparation notes, explicit save and restore controls, an AI session starter, sidebar discoveries, and an optional completion scene. Preparation is optional. Notes are not automatically saved; clients choose what to share and review proposed settings before approving them.
